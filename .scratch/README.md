# .scratch

Specs and tickets for features that are being refined or built: `.scratch/<feature-slug>/spec.md` and
`.scratch/<feature-slug>/issues/NN-slug.md`, written by `/to-spec` and `/to-tickets`. They are committed on
purpose, so the refinement survives a closed chat or a lost laptop (state lives in the repo). See `docs/agents/issue-tracker.md`.
